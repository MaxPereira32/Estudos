## Iniciar o Github na pasta do projeto: 

*Primeiros passos*

git init

git commit -m "primeiro commit"

git branch -M main

git remote add origin https://github.com/SeuUsuario/SeuRepo.git

git push -u origin main

## Para enviar as modificações para o github:

git add .

git commit -m "teste"

git push origin main


## Baixar arquivos do github para o computador

git pull

*Se precisar especificar a origem do (brach)*

git pull origin main
